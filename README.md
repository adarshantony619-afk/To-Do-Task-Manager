# To-Do-Task-Manager
Faircode Assignment 1

Name- Adarsh Antony

Features Implemented
-----------------------------------

1.Add Task – Allows users to create and add new tasks.
2.View Tasks – Displays all added tasks in the task list.
3.Complete Task – Allows users to mark tasks as completed or pending.
4.Edit Task – Allows users to modify existing task names.
5.Delete Task – Allows users to remove unwanted tasks.
